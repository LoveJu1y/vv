# Code of Conduct

## Our Standard

We want LaRA-VLA to be a respectful and constructive collaboration space.

Participants are expected to:

- communicate respectfully
- assume good intent
- give technical feedback without personal attacks
- keep discussions focused on the work
- welcome questions from users with different levels of experience

## Unacceptable Behavior

Examples of unacceptable behavior include:

- harassment or abusive language
- personal attacks or insulting remarks
- deliberate intimidation
- bad-faith disruption of discussions or contributions
- publishing private information without permission

## Enforcement

Project maintainers may remove or moderate comments, issues, discussions, or pull requests that violate this code of conduct.

## Scope

This code of conduct applies to project spaces such as:

- issues
- pull requests
- discussions
- review comments

## Reporting

If you experience or observe unacceptable behavior, report it privately to the maintainers through the repository contact channel.
